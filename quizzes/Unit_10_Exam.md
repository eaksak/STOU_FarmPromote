### ข้อที่ 1. ความแตกต่างสำคัญที่สุดระหว่าง 'การติดตามงาน (Monitoring)' และ 'การประเมินผล (Evaluation)' คือข้อใด?

- ก. การติดตามทำเมื่อโครงการสิ้นสุด ส่วนการประเมินทำก่อนเริ่มโครงการ
- ข. การติดตามเป็นการตรวจสอบความก้าวหน้าอย่างต่อเนื่องตามแผน ส่วนการประเมินผลเป็นการตัดสินคุณค่าและผลสัมฤทธิ์ของโครงการเป็นระยะหรือเมื่อสิ้นสุด
- ค. การติดตามทำโดยเกษตรกร ส่วนการประเมินทำโดยธนาคารพาณิชย์
- ง. ทั้งสองคำมีความหมายเดียวกันทุกประการ
- จ. การประเมินผลไม่มีการเก็บข้อมูลตัวเลข

> **คำตอบที่ถูกต้อง:** ข
> **คำอธิบาย:** Monitoring คือการติดตามตรวจสอบความก้าวหน้า ปัจจัยนำเข้า และกิจกรรมอย่างต่อเนื่องระหว่างทาง ส่วน Evaluation คือการตีค่าคุณค่า ประสิทธิผล ผลลัพธ์ และผลกระทบของโครงการ

### ข้อที่ 2. แบบจำลอง CIPP Model ของ Daniel Stufflebeam องค์ประกอบ 'I' ย่อมาจากคำว่าอะไร?

- ก. Impact Evaluation
- ข. Input Evaluation (การประเมินปัจจัยนำเข้าและความพร้อมของทรัพยากร)
- ค. Implementation Evaluation
- ง. Indicator Evaluation
- จ. Inspection Evaluation

> **คำตอบที่ถูกต้อง:** ข
> **คำอธิบาย:** CIPP Model: Context (บริบท), Input (ปัจจัยนำเข้า), Process (กระบวนการ), Product (ผลผลิต)

### ข้อที่ 3. การประเมินเพื่อปรับปรุงระหว่างดำเนินงาน (Formative Evaluation) มีจุดประสงค์หลักเพื่อสิ่งใด?

- ก. การตัดสินยุติโครงการและเรียกคืนเงินงบประมาณ
- ข. การให้ข้อมูลย้อนกลับเพื่อแก้ไขข้อบกพร่องและปรับปรุงวิธีการทำงานให้มีประสิทธิภาพยิ่งขึ้นระหว่างทาง
- ค. การมอบรางวัลชนะเลิศให้แก่หน่วยงาน
- ง. การจัดทำรายงานประจำปีส่งหอจดหมายเหตุ
- จ. การจัดสรรเงินโบนัสปลายปี

> **คำตอบที่ถูกต้อง:** ข
> **คำอธิบาย:** Formative evaluation มีวัตถุประสงค์เพื่อพัฒนา ปรับปรุง และแก้ไขปัญหาขณะที่โครงการกำลังดำเนินการอยู่ (เปรียบเหมือนพ่อครัวชิมซุปขณะกำลังปรุง เพื่อเติมเครื่องปรุงให้รสชาติดี)

### ข้อที่ 4. การนิเทศงาน (Supervision) ยุคใหม่ในงานส่งเสริมการเกษตร ควรเน้นพฤติกรรมของผู้นิเทศในลักษณะใด?

- ก. การจับผิดและตำหนิต่อหน้าเพื่อนร่วมงาน
- ข. การเป็นโค้ช (Coaching) ให้คำปรึกษา ชี้แนะ และเสริมพลังเพื่อพัฒนาสมรรถนะของเจ้าหน้าที่ผู้ปฏิบัติงาน
- ค. การนั่งสั่งการอยู่ในห้องแอร์โดยไม่เคยลงพื้นที่
- ง. การบังคับให้ทำงานเกินเวลาโดยไม่มีค่าตอบแทน
- จ. การเซ็นชื่อรับรองรายงานโดยไม่อ่านเนื้อหา

> **คำตอบที่ถูกต้อง:** ข
> **คำอธิบาย:** การนิเทศงานเชิงพัฒนา (Developmental Supervision) มุ่งเน้นการสอนงาน (Coaching) เสริมพลัง (Empowerment) และเป็นที่ปรึกษาเพื่อช่วยให้ผู้รับการนิเทศทำงานได้บรรลุเป้าหมาย

### ข้อที่ 5. เครื่องมือวัดผลตอบแทนทางสังคมจากการลงทุน (Social Return on Investment: SROI) มีประโยชน์อย่างไรในงานพัฒนาการเกษตร?

- ก. การคิดดอกเบี้ยเงินกู้ยืม
- ข. การแปลงผลลัพธ์เชิงสังคม สุขภาพ และสิ่งแวดล้อม ออกมาเป็นมูลค่าทางการเงิน เพื่อสะท้อนความคุ้มค่าของการลงทุนภาครัฐ
- ค. การลดอัตราภาษีเงินได้บุคคลธรรมดา
- ง. การตรวจสอบยอดเงินในบัญชีธนาคารของเกษตรกร
- จ. การคำนวณพื้นที่ถือครองที่ดิน

> **คำตอบที่ถูกต้อง:** ข
> **คำอธิบาย:** SROI เป็นกรอบการประเมินที่แปลงคุณค่าทางสังคม ชุมชน และสิ่งแวดล้อมให้เป็นตัวเลขทางการเงิน เพื่อแสดงให้เห็นว่าทุกบาทของงบประมาณสร้างคุณค่าคืนสู่สังคมเท่าใด
