# ระบบติวสอบและสรุปเนื้อหาเข้มข้น มสธ. 91351
## หลักการบริหารการส่งเสริมและพัฒนาการเกษตร (Agricultural Extension and Development Administration)
### มหาวิทยาลัยสุโขทัยธรรมาธิราช (STOU)

ระบบเว็บแอปพลิเคชัน (SPA), คลังข้อสอบปรนัย 750 ข้อ และเอกสารสรุปเนื้อหาเชิงวิชาการรายหน่วย (ความยาว ≥ 3 หน้า A4 ทุกหน่วย) ครบถ้วนทั้ง 15 หน่วยการเรียนรู้ พร้อมเอกสาร PDF ดาวน์โหลดได้ทันที

---

## 🌟 จุดเด่นและเนื้อหาภายในระบบ

### 1. 📑 สรุปเนื้อหารายหน่วยเชิงวิชาการ (15 หน่วยการเรียนรู้)
- สรุปเนื้อหาเชิงวิชาการล้วน **ไม่มีการแทรกวัตถุประสงค์ หรือแนวข้อสอบ** ใด ๆ ในตัวเอกสารสรุป
- ทุกหน่วยมีความยาว **ไม่ต่ำกว่า 3 หน้ากระดาษ A4** (ประมาณ 7,200 – 9,300 ตัวอักษรต่อหน่วย) รวมเนื้อหาทั้งสิ้นกว่า 120,000 ตัวอักษร
- จัดทำเอกสาร PDF คุณภาพสูง สวยงาม อ่านง่าย พร้อมดาวน์โหลด:
  - **PDF รายหน่วย 15 ไฟล์:** `content_summaries/pdf/Unit_01_Content_Summary.pdf` ถึง `Unit_15_Content_Summary.pdf`
  - **PDF เล่มรวม 15 หน่วยการเรียนรู้ (Master Booklet):** `content_summaries/pdf/Farm_Promote_15_Units_Content_Summary.pdf` (ความยาว 73 หน้า A4)

### 2. 📝 คลังข้อสอบปรนัย 750 ข้อ (50 ข้อต่อหน่วย x 15 หน่วย)
- ข้อสอบปรนัย **5 ตัวเลือก (ก, ข, ค, ง, จ)** พร้อมเฉลยละเอียดและคำอธิบายอ้างอิงเชิงวิชาการทุกข้อ
- รองรับการฝึกทำข้อสอบผ่านระบบ Interactive Web App:
  - โหมดฝึกทำแบบเลือกหน่วย หรือสุ่มทำข้อสอบแบบจับเวลา
  - บันทึกคะแนนและแสดงจุดที่ควรทบทวน
- เอกสารรวมข้อสอบเพื่อการพิมพ์/ทบทวน:
  - `quizzes/Printable_Exam_Booklet.html`
  - `quizzes/Farm_Promote_Exam_750_Questions.pdf` (ความยาว 256 หน้า A4)

### 3. 💻 ระบบ Web Application (Single Page Application - SPA)
- โทนสีและสไตล์: **Deep Navy Blue & Emerald Green** ทันสมัย สบายตา รองรับทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
- เมนูครบครัน:
  1. `🏠 ภาพรวม` - โครงสร้างหลักสูตรและสารบัญ 15 หน่วย
  2. `📑 สรุปเนื้อหารายหน่วย` - อ่านสรุปเนื้อหาขนาดยาว ≥ 3 A4 พร้อมปุ่มดาวน์โหลด PDF
  3. `📚 สรุป 15 หน่วย` - ทบทวนสาระสำคัญแบบรวดเร็ว
  4. `📝 คลังข้อสอบ (750 ข้อ)` - ฝึกทำข้อสอบพร้อมเฉลยละเอียด
  5. `🗂️ แฟลชการ์ด` - บัตรคำศัพท์ แนวคิด และโมเดลการบริหาร
  6. `🔍 ถามติวเตอร์ AI` - ค้นหาเนื้อหาและแนวคิดสำคัญ

## 🚀 วิธีการใช้งานและการ Deploy

### 1. เปิดใช้งานในเครื่องคอมพิวเตอร์ (Local):
- ดับเบิลคลิกเปิดไฟล์ `preview.html` ในเบราว์เซอร์ (Chrome, Edge) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

### 2. นำขึ้น GitHub Pages:
1. สร้างคลังข้อมูลใหม่ (Repository) บน GitHub
2. รันคำสั่งหรือดับเบิลคลิก `push_to_github.bat` เพื่อนำโค้ดขึ้น GitHub
3. ไปที่ **Settings -> Pages** บน GitHub แล้วเลือก Source เป็น `main` branch โฟลเดอร์ `/(root)` แล้วกด Save

### 3. นำขึ้น Google Apps Script (GAS):
- ดูขั้นตอนโดยละเอียดได้ที่ไฟล์ DEPLOY_GAS.md
